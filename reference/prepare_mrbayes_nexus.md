# Generate a NEXUS File with an Embedded MrBayes Block

Sanitizes sequence labels, writes a `DNAbin` alignment to a NEXUS file,
appends a generated `MrBayes` block, and returns the output file path.

## Usage

``` r
prepare_mrbayes_nexus(
  alignment,
  output_path,
  mcmc_options = NULL,
  partition = T,
  loci_length,
  loci_name,
  protein_coding_loci,
  lset_options,
  prset_options = NULL,
  sum_options = NULL
)
```

## Arguments

- alignment:

  A `DNAbin` alignment object.

- output_path:

  Character. Output file path (with or without a `.nexus` extension).

- mcmc_options:

  Named list or `NULL`. Arguments passed to
  [`mrbayes_mcmc_cmd()`](https://zzzhehao.github.io/zbarc/reference/mrbayes.md).
  Default is `NULL`.

- partition:

  Logical. Whether to include a partition scheme generated by
  [`mrbayes_partition_cmd()`](https://zzzhehao.github.io/zbarc/reference/mrbayes.md).
  Default is `TRUE`.

- loci_length:

  Numeric vector. Length of each locus, passed to
  [`mrbayes_partition_cmd()`](https://zzzhehao.github.io/zbarc/reference/mrbayes.md).

- loci_name:

  Character vector. Name of each locus, passed to
  [`mrbayes_partition_cmd()`](https://zzzhehao.github.io/zbarc/reference/mrbayes.md).

- protein_coding_loci:

  Character vector. Names of protein-coding loci, passed to
  [`mrbayes_partition_cmd()`](https://zzzhehao.github.io/zbarc/reference/mrbayes.md).

- lset_options:

  Named list or list of named lists. Arguments passed to
  [`mrbayes_lset_cmd()`](https://zzzhehao.github.io/zbarc/reference/mrbayes.md).

- prset_options:

  Named list, list of named lists, or `NULL`. Arguments passed to
  [`mrbayes_prset_cmd()`](https://zzzhehao.github.io/zbarc/reference/mrbayes.md).
  Default is `NULL`.

- sum_options:

  Named list, list of named lists, or `NULL`. Arguments passed to
  [`mrbayes_sum_cmd()`](https://zzzhehao.github.io/zbarc/reference/mrbayes.md).
  Default is `NULL`.

## Value

Character path to the written NEXUS file.
