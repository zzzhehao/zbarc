# Build a local BLAST reference database from a BOLD BCDM TSV

Build a local BLAST reference database from a BOLD BCDM TSV

## Usage

``` r
bcdm2blastdb(bcdm_path, db_dir, db_name = "bold_ref_db")
```

## Arguments

- bcdm_path:

  Character. Path to the BCDM TSV file generated by
  [`bold_retrieve()`](https://zzzhehao.github.io/zbarc/reference/bold_retrieve.md).

- db_dir:

  Character. Directory to save the formatted FASTA and BLAST database
  files.

- db_name:

  Character. Base name for the output BLAST database files. Default is
  `"bold_ref_db"`.

## Value

Invisibly returns the base path to the compiled BLAST database
(`file.path(db_dir, db_name)`).
