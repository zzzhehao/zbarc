# Plot Distance Histogram from an ABGD Distance Matrix File

Plot Distance Histogram from an ABGD Distance Matrix File

## Usage

``` r
abgd_disthist(distmat_path)
```

## Arguments

- distmat_path:

  Character. Path to the `*_distmat.txt` file generated by ABGD.

## Value

A `ggplot` histogram object.
