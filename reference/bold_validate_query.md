# Validate Query Triplets via BOLD Preprocessor

Query triplets should be validated and matched before requesting query
tokens. This step is automatically applied to queries generated by
[`bold_get_query()`](https://zzzhehao.github.io/zbarc/reference/bold_get_query.md)

## Usage

``` r
bold_validate_query(query, max_chars = 240)
```

## Arguments

- query:

  Character string of semicolon-separated query triplets (e.g.,
  `"tax:Aves;geo:Argentina"`).

- max_chars:

  Integer. Maximum character length per preprocessor request chunk.
  Default is `240`.

## Value

A list containing `successful_terms` returned by the BOLD query
preprocessor API.
