# Polish Sequence Alignment

**\[deprecated\]** Deprecated in version `0.0.1.9001` because alignment
polishing in DNA barcoding is better performed manually with visual
inspection.

## Usage

``` r
polish_alignment(aln, verbose = T)
```

## Arguments

- aln:

  A `DNAbin` alignment object.

- verbose:

  Logical. Whether to print status messages via `cli`. Default is
  `TRUE`.

## Value

A `DNAbin` object containing the polished alignment.
