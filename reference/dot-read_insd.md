# Extract INSD Metadata from an XML File Downloaded from NCBI GenBank

Extract INSD Metadata from an XML File Downloaded from NCBI GenBank

## Usage

``` r
.read_insd(xml)
```

## Arguments

- xml:

  Character. File path to an INSD XML file.

## Value

A `data.frame` of flattened sequence, feature qualifier, and reference
metadata.
